# MICE Namibia Website

A multi-page static site for a Meetings, Incentives, Conferences & Exhibitions
(MICE) destination management business operating across Namibia, Botswana,
South Africa, Zambia, Zimbabwe, Kenya, Tanzania, Uganda, and Rwanda. Built
from a client-supplied design brief based on the "Confevo" event/conference
theme, with original blog content and venue photography already provided.

No confirmed brand name yet — see `CLAUDE.md`.
